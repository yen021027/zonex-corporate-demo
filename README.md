# ZONEX TRANSPORT · PatchFactory-inspired redesign

Independent Next.js / React / TypeScript / Tailwind CSS / Framer Motion preview. Existing website and older demo are untouched.

## Run
`npm install`
`npm run dev`
Open http://localhost:3026

## Production
`npm run build` generates the static site in `out/`. No backend, database, tracking, or credentials are required. Do not deploy `node_modules`, logs, or source research.

## Sources and design
Actual desktop and 390px mobile visual inspection of https://patchfactory.com/ informed the full-bleed image hero, overlay/sticky navigation, restrained navy/white/gray palette, centered section introductions, photographic columns, generous spacing, alternating image-text sections, and dark footer. Its brand, content and assets are not used.

Business content, original logo geometry, public optimized photos, phone numbers, address and LINE destination were verified against https://zonex-transport.com.tw/. No invented statistics or testimonials. Images copied from the prior demo's already-public optimized assets, with filenames confirmed against the official source.

UI UX Pro Max was consulted; generic operations-dashboard, live-map and metrics recommendations were deliberately rejected because they conflict with the explicit brief. This is a marketing website, not a tracking platform.

Demo is noindex with the existing official site as canonical to avoid duplicate indexing. Change these intentionally only when replacing the official website. Public deployment is not performed by this build.
